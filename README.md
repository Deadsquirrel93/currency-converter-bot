# Currency Converter Telegram Bot

🇷🇺 Русская документация | [🇬🇧 English documentation](README.en.md)

Telegram-бот на Go, который конвертирует суммы между валютами. Доступ можно ограничить whitelist по Telegram ID или оставить открытым для всех.

## Возможности

- интерфейс на русском и английском языках; при первом обращении бот предлагает выбрать язык кнопками 🇷🇺/🇬🇧, а `/lang en` и `/lang ru` позволяют сменить его позже
- whitelist пользователей через `TELEGRAM_ALLOWED_USER_IDS` и runtime-файл `ALLOWED_USERS_FILE`; если админы, env whitelist и runtime whitelist пустые, бот доступен всем
- админы через `TELEGRAM_ADMIN_USER_IDS`: команды `/allow`, `/disallow`, `/allowed` добавляют и удаляют пользователей по Telegram ID без деплоя
- команды `/lang en`, `/from USD`, `/to EUR`, `/swap`, `/rate USD EUR`, `/chart USD RUB`, `/subscribe 09:00 USD RUB`, `/subscribe new USD RUB`, `/subscription`, `/unsubscribe`, `/tz Europe/Moscow`, `/alert USD RUB > 95`, `/alerts`, `/with USD EUR RUB`, `/with_modify yes`, `/inline_modify yes`, `/multi 1000`, `/round auto`, `/modify_from 1.5`, `/modify_to 1.5`, `/reset`, `/delete`, `/settings`, `/whoami`, `/help`, `/list`
- inline mode: `@your_bot 100 usd rub`
- ввод суммы свободным текстом: `12 345,67 usd` -> `12345.67`
- разделители тысяч: `1 000 000`, `1.000.000` и `1,000,000` читаются как миллион; одиночная запятая считается десятичной (`1,5` -> `1.5`), но в английском интерфейсе `1,000` читается как `1000`
- если в строке несколько отдельных чисел (`iPhone 15 за 1000`, `2 кофе по 350`), бот не склеивает их, а просит оставить одно число или перемножить: `2 x 350`; перед знаком умножения может стоять валюта: `100 usd x 9`
- умножение количества на цену в строке: `100х9`, `100 x 9`, `100 * 9`
- выражения в сумме: `100+50 usd`, `(12*3)+5`, `1 000 / 4`; даты и телефоны (`12-05-2024`, `8-800-555-35-35`) не превращаются в вычитание
- быстрый перевод без смены настроек: `100 usd to eur`, `100$ в руб`, `250 евро`
- для быстрого перевода с явно указанными валютами `/multi` не применяется; `/modify_from` и `/modify_to` включаются отдельно через `/inline_modify yes`
- алиасы и символы популярных валют: `$`, `€`, `₽`, `руб`, `сум`, `баксы`, `тенге`
- итоговая сумма в ответе выделяется жирным, рядом показывается точный курс за 1 единицу и удобный номинал для мелких курсов
- `/rate` показывает текущий курс с динамикой относительно вчера, 7 дней назад, минимумом и максимумом за 30 дней и кнопкой «📈 График за 30 дней»
- `/chart` присылает график курса за 30 дней картинкой
- подписка на новый курс ЦБ: сообщение приходит, как только ЦБ установил курс на следующий день
- алерты по порогу: `/alert USD RUB > 95` сообщит один раз, когда курс ЦБ пересечет порог
- ввод нескольких сумм с новой строки: бот сложит их и переведет итог
- курсы валют из официального XML ЦБ РФ
- ежедневная подписка на курс валютной пары в заданное время с динамикой относительно вчера, 7 дней назад, минимумом и максимумом за 30 дней
- свой часовой пояс у каждого пользователя (`/tz`); по умолчанию — `SUBSCRIPTION_TIMEZONE`
- файловый кеш курсов на 60 минут (настраивается через `RATES_CACHE_TTL`)
- сохранение пользовательских настроек в `data/user_settings.json`
- сохранение подписок в `data/subscriptions.json` и `data/new_rate_subscriptions.json`, алертов — в `data/alerts.json`
- graceful shutdown по `SIGINT`/`SIGTERM`
- Docker multi-stage build и `restart: unless-stopped` в Compose

## Запуск

1. Скопируйте пример конфига:

```bash
cp .env.example .env
```

2. Заполните `.env`:

```dotenv
TELEGRAM_BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
TELEGRAM_ADMIN_USER_IDS=YOUR_TELEGRAM_USER_ID
TELEGRAM_ALLOWED_USER_IDS=YOUR_TELEGRAM_USER_ID,ANOTHER_TELEGRAM_USER_ID
DEFAULT_FROM=USD
DEFAULT_TO=RUB
RATES_CACHE_FILE=/app/data/rates_cache.json
USER_SETTINGS_FILE=/app/data/user_settings.json
ALLOWED_USERS_FILE=/app/data/allowed_users.json
SUBSCRIPTIONS_FILE=/app/data/subscriptions.json
NEW_RATE_SUBSCRIPTIONS_FILE=/app/data/new_rate_subscriptions.json
ALERTS_FILE=/app/data/alerts.json
SUBSCRIPTION_TIMEZONE=Asia/Tashkent
CBR_DAILY_URLS=https://www.cbr.ru/scripts/XML_daily.asp
```

Пути к файлам данных необязательны: по умолчанию все файлы создаются в папке `data` рядом с бинарником, то есть в `/app/data` внутри контейнера.

Чтобы сделать бота публичным для всех пользователей Telegram, оставьте пустыми админов, env whitelist и runtime whitelist:

```dotenv
TELEGRAM_ADMIN_USER_IDS=
TELEGRAM_ALLOWED_USER_IDS=
```

Если задан `TELEGRAM_ADMIN_USER_IDS`, `TELEGRAM_ALLOWED_USER_IDS` или в `ALLOWED_USERS_FILE` есть пользователи, обычные сообщения, кнопки и inline mode будут работать только для админов и разрешенных Telegram ID. Админы всегда имеют доступ.

3. Подготовьте папку для кеша курсов и пользовательских настроек:

```bash
mkdir -p data
sudo chown -R 10001:10001 data
```

Бот внутри контейнера запускается от пользователя с UID/GID `10001`, поэтому папка `data` на хосте должна быть доступна этому пользователю. Если вы работаете на сервере из-под `root`, папка после `git pull`, распаковки архива или ручного создания может снова оказаться `root:root`; в таком случае повторите `sudo chown -R 10001:10001 data`.

4. Запустите:

```bash
docker compose up -d --build
```

## Деплой

Для обновления уже развернутого бота используйте:

```bash
./deploy.sh
```

Скрипт делает `git pull --ff-only`, пересобирает образ и перезапускает сервисы через Docker Compose:

```bash
docker compose up -d --build --force-recreate --remove-orphans
```

Если настройки не сохраняются, проверьте логи:

```bash
docker compose logs bot
```

Ошибка вида `permission denied` для файлов в `/app/data` означает, что папка `data` на хосте недоступна пользователю контейнера.

Контейнер запускается с защитой: корневая файловая система только для чтения (писать можно только в `/app/data`), все capabilities сброшены, `no-new-privileges`, лимиты памяти и процессов. Логи ограничены тремя файлами по 10 МБ, поэтому не забьют диск.

Бот создает файлы данных с правами `600`, а папку — с правами `700`, потому что в них Telegram ID пользователей. Для уже существующей папки права можно выставить из контейнера (владелец — пользователь контейнера):

```bash
docker compose exec bot sh -c 'chmod 700 /app/data && chmod 600 /app/data/*.json'
```

Если файл настроек, подписок или whitelist поврежден и не читается, бот не затирает его пустыми данными: он переименовывает файл в `*.corrupt-<время>`, пишет ошибку в лог и продолжает работу. Данные можно восстановить из этого файла вручную.

Быстрая проверка прав:

```bash
ls -la data
```

Если видите `root root`, исправьте:

```bash
sudo chown -R 10001:10001 data
docker compose restart bot
```

## Использование

В Telegram:

```text
/lang en
/from USD
/to RUB
12 345,67
100 usd to rub
100$ в руб
```

Бот ответит конвертацией из `USD` в `RUB`.

Можно отправить несколько сумм одним сообщением:

```text
100
200,50
15
```

Бот сложит строки и переведет итоговую сумму.

В строках с покупками можно умножать два числа через `х`, `x` или `*`; русская и английская буквы поддерживаются:

```text
70 х 5 литров молока
12 x 4 кг курицы
100*9
```

Такие строки будут посчитаны как `350`, `48` и `900`, а затем сложены с остальными строками.

В сумме можно писать выражения со скобками и действиями `+`, `-`, `*`, `/` (а также `×`, `÷`, `х`):

```text
100+50 usd
(12*3)+5
1 000 / 4
100 usd + 50 usd
```

Умножение и деление выполняются раньше сложения и вычитания. Минус между числами без пробелов (`12-05-2024`, `8-800-555-35-35`, `10-15 usd`) считается частью даты, телефона или диапазона, а не вычитанием; для вычитания ставьте пробелы: `100 - 50`. Внутри выражения с другими действиями или скобками минус работает и без пробелов: `(100-50)*2`. Деление на ноль, отрицательный результат, выражение длиннее 200 символов или глубже 10 уровней скобок дают понятную ошибку.

Для inline mode включите режим у BotFather (`/setinline`), затем пишите в любом чате:

```text
@your_bot 100 usd rub
```

Если списки доступа пустые, inline mode доступен всем. Если задан админ, env whitelist или runtime whitelist, inline-ответы получат только разрешенные Telegram ID. Пока пользователь не выбрал язык в личном чате с ботом, inline-ответы приходят на языке его Telegram-клиента: английский для `en`, для остальных русский.

Выбранные пользователями настройки сохраняются в `data/user_settings.json`. Пользователи, добавленные админом через `/allow`, сохраняются в `data/allowed_users.json`. В Docker Compose папка `./data` подключена как volume, поэтому настройки и runtime whitelist сохраняются после пересборки образа и перезапуска контейнера.

При `/start` или первом сообщении пользователя без сохраненного языка бот показывает кнопки `🇷🇺 Русский` и `🇬🇧 English`. Выбор сохраняется в `data/user_settings.json`. Сменить язык можно командами `/lang ru` и `/lang en`; команда `/lang` без аргумента снова показывает кнопки. `/reset` сохраняет выбранный язык, а `/delete` удаляет его вместе с остальными настройками.

`/help` показывает справку, а `/list` возвращает список поддерживаемых популярных валют с кодом, названием и страной.

`/whoami` показывает числовой Telegram ID пользователя. Если доступ ограничен, пользователь может отправить `/whoami` или `/start` и передать ID администратору.

Админские команды:

```text
/allow 123456789
/disallow 123456789
/allowed
```

`/allow` добавляет пользователя в runtime whitelist без деплоя, `/disallow` удаляет только пользователей, добавленных через `/allow`, а `/allowed` показывает админов, env whitelist и runtime whitelist. Добавление по `@username` намеренно не поддерживается: username может измениться, а Telegram Bot API не гарантирует получение числового user ID по произвольному username.

`/settings` показывает язык, текущую валютную пару, время обновления курсов, кнопки `/with`, множитель, округление и процентные модификаторы.

`/rate USD RUB` показывает текущий курс пары без конвертации суммы, разницу со вчера, разницу с курсом ровно 7 дней назад, минимальный и максимальный курс за последние 30 дней. Для минимума и максимума бот также показывает отклонение текущего курса. Можно писать алиасами: `/rate $ руб`, `/rate сум евро`. Если валюты не указаны, используется текущая пара из настроек.

ЦБ устанавливает курс по рабочим дням (обычно во второй половине дня по Москве), и он вступает в силу на следующий календарный день. После публикации `/rate` показывает уже курс на завтра и пишет его дату («Курс ЦБ на 29.09.2026»), а «со вчера» считается относительно курса, который действует сегодня. Дни в истории считаются в часовом поясе пользователя (`/tz`).

Под ответом `/rate` есть кнопка «📈 График за 30 дней».

`/chart USD RUB` присылает график курса за 30 дней картинкой, а в подписи — последний курс, изменение за период, минимум и максимум. Без валют используется пара из настроек. Картинка рисуется в памяти, без внешних библиотек.

`/subscribe 09:00` включает ежедневную отправку курса текущей пары из настроек. Можно указать пару явно: `/subscribe 09:00 USD RUB`. В сообщении бот покажет текущий курс, разницу со вчера, разницу с курсом ровно 7 дней назад, минимальный и максимальный курс за последние 30 дней. Для минимума и максимума бот также показывает отклонение текущего курса. Время считается в часовом поясе пользователя (см. `/tz` ниже), а если пользователь его не выбирал — в `SUBSCRIPTION_TIMEZONE` (имя из базы IANA, например `Asia/Tashkent` или `Europe/Moscow`; по умолчанию `Asia/Tashkent`). База часовых поясов встроена в бинарник, поэтому отдельный `tzdata` в образе не нужен. Если имя в `SUBSCRIPTION_TIMEZONE` указано с ошибкой, бот не запустится и напишет причину в лог. У пользователя может быть одна ежедневная подписка: повторный `/subscribe 09:00` заменяет ее, а курс приходит в тот чат, где была отправлена команда. Если указать время, которое сегодня уже прошло, бот сразу пришлет текущий курс, а следующее сообщение придет завтра. Если бот был выключен в момент отправки, после запуска он отправит курс за текущий день, если время уже наступило.

`/tz Europe/Moscow` задает часовой пояс пользователя для ежедневной подписки и дней в истории `/rate`. Принимаются имена IANA (регистр не важен: `europe/moscow`), `мск`, `UTC` и смещения `+3`, `UTC+3`, `GMT+05:30`. `/tz` показывает текущий пояс и время, `/tz default` возвращает пояс по умолчанию. При смене пояса бот переносит дату последней отправки, чтобы подписка не пришла дважды и не пропала: если в новом поясе следующая отправка оказалась бы меньше чем через 12 часов после прошлой, она пропускается.

`/subscribe new USD RUB` — подписка на новый курс ЦБ: сообщение приходит, как только ЦБ установил курс на следующий день, с изменением к текущему курсу. Одно сообщение на каждую дату курса. Если курс на завтра уже вышел в момент подписки, бот пришлет его сразу. Ее можно держать вместе с ежедневной подпиской. Бот проверяет ЦБ раз в 10 минут с 15:30 до 20:00 по Москве и раз в час в остальное время, и только если есть подписчики или алерты.

`/subscription` показывает подписки. `/unsubscribe` отключает все, `/unsubscribe daily` — только ежедневную, `/unsubscribe new` — только подписку на новый курс. Также можно отключить все через `/subscribe off`.

## Алерты

```text
/alert USD RUB > 95
/alert EUR RUB < 90,5
/alert > 95
/alerts
/alert off 2
```

`/alert` сообщит один раз, когда курс ЦБ пересечет порог, и после этого удалится. Условия: `>`, `<`, `>=`, `<=`, а также слова `выше` и `ниже`. Без валют используется пара из настроек. Если условие уже выполнено по текущему курсу, алерт не создается. Проверка идет вместе с проверкой нового курса ЦБ (см. `/subscribe new`), сообщение приходит в чат, где был создан алерт.

`/alerts` показывает список с текущим курсом и кнопками удаления. Удалить можно и командой `/alert off N` или сразу все — `/alert off all`. Номера алертов не сдвигаются после удаления. У пользователя может быть не больше 10 алертов.

`/swap` меняет исходную и итоговую валюты местами. Например, было `USD -> RUB`, станет `RUB -> USD`.

`/reset` сбрасывает настройки пользователя к значениям по умолчанию из `.env` и сохраняет этот сброс в `USER_SETTINGS_FILE`. Язык и часовой пояс сохраняются.

`/delete` удаляет все данные пользователя: настройки, выбранный язык и часовой пояс, подписки и алерты. При следующем сообщении бот снова предложит выбрать язык, дальше будут действовать настройки по умолчанию.

`/with USD EUR RUB` добавляет к ответу кнопки `в USD`, `в EUR`, `в RUB`. При нажатии бот пересчитает ту же введенную сумму из исходной валюты в валюту кнопки. `/with off` отключает кнопки.

`/with_modify yes` включает учет `/modify_from` и `/modify_to` для перевода по кнопкам. По умолчанию используется `no`, то есть кнопки учитывают множитель `/multi`, но не учитывают процентные модификаторы.

`/inline_modify yes` включает учет `/modify_from` и `/modify_to` для сообщений с явно указанными валютами, например `100 USD to RUB` или `100$ в руб`. По умолчанию используется `no`: такие быстрые переводы не учитывают ни `/modify_from`, ни `/modify_to`, ни `/multi`. Даже после `/inline_modify yes` множитель `/multi` для явных валют не применяется.

`/multi 1000` умножает входную сумму перед расчетом. Например, если выбран `UZS`, можно указать `/multi 1000`, затем писать `45`, а бот будет считать это как `45000`. По умолчанию множитель равен `1`, он же используется для сброса.

`/round auto` управляет округлением итоговой суммы. Доступные значения: `auto`, `0`, `2`, `4`, `6`. В режиме `auto` бот показывает мелкие значения точнее, чтобы не превращать их в `0,00`.

`/modify_to 1.5` добавляет 1,5% к результату конвертации. Например, если без модификатора было `100 USD = 1000 RUB`, то с `/modify_to 50` будет `100 USD = 1500 RUB`.

`/modify_from 1.5` меняет входную сумму перед конвертацией. Например, с `/modify_from 50` сумма `100 USD` сначала станет `150 USD`, а потом будет пересчитана в итоговую валюту. Для сброса используйте `0`.

Ограничения: процент модификатора — больше `-100` и не больше `1000`, множитель `/multi` — не больше миллиарда, сумма — не больше 10^15, выражение — не длиннее 200 символов и не глубже 10 уровней скобок, алертов — не больше 10 на пользователя.

## Группы

Бота можно добавить в группу. Там он реагирует только на команды (`/rate` или `/rate@имя_бота`), на сообщения, которые начинаются с `@имя_бота` (например `@имя_бота 100 usd`), и на ответы на свои сообщения. Остальную переписку он игнорирует. Пользователям не из whitelist бот в группах ничего не отвечает.

## Защита от флуда и сбоев

- Один пользователь может отправить боту до 30 запросов в минуту; при превышении бот один раз предупреждает и до конца минуты молчит.
- Пользователь не из whitelist получает сообщение об ограничении доступа не чаще раза в 10 минут.
- Курсы за прошлые дни кешируются в памяти: `/rate` и подписки не запрашивают у ЦБ одни и те же даты повторно, а сбор истории ограничен по времени.
- Если пользователь заблокировал бота или бота удалили из группы, подписка удаляется. При временных ошибках Telegram бот повторяет отправку через 5, 15 и 45 минут, затем откладывает до следующего дня.
- Так же отправляются новый курс и алерты: недоступный чат — подписка или алерты в этом чате удаляются; временная ошибка — повтор через 5, 15 и 45 минут, затем новый курс пропускается до следующей даты, а алерт снимается.
- Если админ убрал пользователя через `/disallow`, подписки и алерты перестают приходить (и возобновятся, если доступ вернут).
- При недоступности Telegram пауза между попытками растет от 3 секунд до минуты; ответ `429 Too Many Requests` учитывается.
- Админские команды `/allow`, `/disallow`, `/allowed` видны в меню только админам (чтобы меню обновилось, админ должен хотя бы раз написать боту).

Бот работает с валютами из списка `/list`: `RUB` как базовая валюта и популярные валюты, которые публикует ЦБ РФ. Курсы берутся из ежедневных данных ЦБ РФ, пересчет между двумя иностранными валютами идет через рубль.

Если ЦБ РФ иногда сбрасывает соединение, можно указать несколько XML-совместимых источников через запятую:

```dotenv
CBR_DAILY_URLS=https://www.cbr.ru/scripts/XML_daily.asp,https://cbr.ru/scripts/XML_daily.asp
```

Бот попробует каждый источник несколько раз и сохранит успешный ответ в кеш. Старое имя переменной `CBR_DAILY_URL` тоже поддерживается.

Дополнительные настройки:

- `RATES_CACHE_TTL` — сколько хранить курсы в кеше, по умолчанию `60m`; если ЦБ недоступен, бот использует последний сохраненный кеш
- `TELEGRAM_API_BASE` — адрес Bot API, по умолчанию `https://api.telegram.org` (нужен для своего Bot API сервера)
- `SUBSCRIPTION_TIMEZONE` — часовой пояс по умолчанию для пользователей, которые не выбрали свой через `/tz`
- `NEW_RATE_SUBSCRIPTIONS_FILE` — файл подписок на новый курс, по умолчанию `data/new_rate_subscriptions.json`
- `ALERTS_FILE` — файл алертов, по умолчанию `data/alerts.json`
